📐 Règles de construction

À respecter pour toute nouvelle icône ajoutée à l'écosystème FlowPilot.

Structure SVG type
<svg viewBox="0 0 32 32" width="28" height="28"> <!-- Fond pastel arrondi --> <rect width="32" height="32" rx="8" fill="#FFF3E0"/> <!-- Forme de l'icône, couleur de marque --> <rect x="2" y="18" width="6" height="12" rx="2" fill="#EF9F27"/> </svg>

Règles
1. viewBox toujours "0 0 32 32" — la grille de référence ne change jamais 2. Fond : rx="8" (coins arrondis), couleur pastel claire (opacité visuelle ~10-15%) 3. Icône : couleur de marque pleine, formes géométriques simples (rect/circle/path) 4. Pas de texte SVG sauf pour KPI (valeur d'exemple type "1,2M") 5. Icônes "outils" (navigation, actions) : fond plein + traits blancs pour contraster avec les icônes "widgets" qui ont fond pastel + traits colorés 6. Aucune dépendance externe : pas de , pas de police d'icônes, pas de vers un sprite distant 7. Taille d'affichage recommandée : 28px (liste), 56px (carte large), 64px (écran onboarding)
